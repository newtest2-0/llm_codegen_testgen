# LLM代码生成平台 - 一键启动指南

## 🚀 快速启动

本项目提供了多种一键启动方式，选择适合您的操作系统和偏好的方法：

### Windows用户

#### 方法1：批处理文件（最简单）
```bash
# 双击运行或在命令提示符中执行
run.bat
```

#### 方法2：PowerShell脚本（推荐）
```powershell
# 在PowerShell中执行
.\run.ps1
```

#### 方法3：Python脚本（跨平台）
```bash
python run.py
```

### macOS/Linux用户

#### 方法1：Python脚本（推荐）
```bash
python3 run.py
```

#### 方法2：原始启动脚本
```bash
python3 scripts/start.py
```

## 🛠️ 首次使用

如果是第一次使用，建议先运行环境设置脚本：

```bash
python setup.py
```

这将会：
- 检查系统要求
- 创建虚拟环境
- 安装所有依赖
- 验证配置文件
- 创建环境变量示例
- 运行基础测试

## 🔧 配置要求

### 1. Python环境
- Python 3.8 或更高版本
- pip 包管理器

### 2. API密钥配置
您需要配置至少一个AI提供者的API密钥。支持的提供者包括：

- **OpenAI**: GPT-4, GPT-3.5-turbo
- **DeepSeek**: DeepSeek-Chat
- **Anthropic**: Claude-3.5-Sonnet
- **Google**: Gemini-1.5-Flash
- **通义千问**: Qwen-Plus
- **百川**: Baichuan4
- **智谱**: GLM-4-Plus
- **Ollama**: 本地部署模型

### 3. 环境变量设置

#### 方法1：创建.env文件
```bash
# 复制示例文件
cp .env.example .env
# 编辑.env文件，填入您的API密钥
```

#### 方法2：设置系统环境变量
```bash
# Windows (命令提示符)
set OPENAI_API_KEY=your_api_key_here

# Windows (PowerShell)
$env:OPENAI_API_KEY="your_api_key_here"

# macOS/Linux
export OPENAI_API_KEY=your_api_key_here
```

## 🔍 故障排除

### 常见问题

#### 1. Python版本不兼容
```
❌ 错误：需要Python 3.8或更高版本
```
**解决方案**: 安装Python 3.8+，下载地址：https://www.python.org/downloads/

#### 2. 虚拟环境创建失败
```
❌ 虚拟环境创建失败
```
**解决方案**: 
- 确保有足够的磁盘空间
- 检查Python是否正确安装
- 尝试手动创建：`python -m venv .venv`

#### 3. 依赖安装失败
```
❌ 依赖安装失败
```
**解决方案**:
- 检查网络连接
- 更新pip：`python -m pip install --upgrade pip`
- 使用国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple/`

#### 4. 配置文件错误
```
❌ 错误：未找到config.json配置文件
```
**解决方案**: 确保config.json文件存在且格式正确

#### 5. API密钥未配置
```
⚠️ 尚未配置任何API密钥
```
**解决方案**: 按照上述环境变量设置方法配置API密钥

### PowerShell执行策略问题

如果在Windows上运行PowerShell脚本时遇到执行策略错误：

```powershell
# 临时允许执行
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 端口占用问题

如果8000或8080端口被占用：

1. 查找占用进程：
```bash
# Windows
netstat -ano | findstr :8000
netstat -ano | findstr :8080

# macOS/Linux
lsof -i :8000
lsof -i :8080
```

2. 结束占用进程或修改配置文件中的端口设置
