# Professional Code Development Platform - 启动指南

## 🚀 快速启动（推荐）

### 方法1：最简单的方式（2步）

#### 第1步：启动后端服务
```bash
cd backend
python -m uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```

#### 第2步：启动前端服务（新开一个终端）
```bash
cd web
python start_server.py
```

#### 第3步：访问系统
打开浏览器访问：**http://localhost:8080**

## 🔧 故障排查

### 问题1：后端启动失败

**错误**: `ModuleNotFoundError: No module named 'uvicorn'`

**解决**:
```bash
pip install -r requirements.txt
```

### 问题2：前端无法访问后端API

**原因**: CORS跨域问题

**解决**: 确保后端在8000端口运行，前端在8080端口访问

### 问题3：端口被占用

**错误**: `Address already in use`

**解决**:
```bash
# Windows - 查找占用端口的进程
netstat -ano | findstr :8000
netstat -ano | findstr :8080

# 结束进程
taskkill /F /PID <进程ID>
```

### 问题4：编码错误（Windows）

**错误**: `UnicodeEncodeError: 'gbk' codec`

**解决**: 使用 `quick_start.py` 脚本，它已经处理了编码问题

## 🎯 启动后第一步

### 1. 配置API密钥（可选）

访问系统后：
1. 点击顶部导航的"系统设置"标签
2. 展开要配置的AI提供者
3. 输入API密钥
4. 点击"保存"

### 2. 尝试UML图表功能

1. 在"详细需求描述"中输入需求
2. 点击"生成用例图"按钮
3. 查看AI生成的UML图表
4. 继续生成其他图表
5. 点击"基于图表生成代码"

### 3. 使用完整工作流

1. 填写所有5个模块的文本内容
2. 点击右侧导航的"完整工作流"按钮
3. 系统自动生成所有图表并生成代码
