## 🐛 修复的问题

### 问题1：前端启动编码错误
**错误信息**：
```
UnicodeEncodeError: 'gbk' codec can't encode character '\u2705' in position 0
```

**原因**：`web/start_server.py` 使用了emoji字符，Windows控制台默认GBK编码无法显示

**解决方案**：
- ✅ 添加UTF-8编码设置
- ✅ 移除emoji，使用 `[OK]`、`[Info]` 等标签格式
- ✅ 美化启动输出信息

### 问题2：后端日志编码问题
**状态**：✅ 已处理
- logger通常能处理UTF-8，但为了保险，已在关键启动脚本中添加编码设置

## 🚀 推荐的启动方式

### ⭐ 方式1：快速启动（最简单）⭐⭐⭐⭐⭐

#### Windows
```bash
# 双击运行
quick_start.bat

# 或命令行
python quick_start.py
```

#### Linux/Mac
```bash
python quick_start.py
```

**优点**：
- 无需虚拟环境
- 启动速度快
- 已处理所有编码问题

---

### ⭐ 方式2：分别启动（最稳定）⭐⭐⭐⭐⭐

#### 终端1 - 启动后端
```bash
cd backend
python -m uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```

#### 终端2 - 启动前端
```bash
cd web
python start_server.py
```

**优点**：
- 可以单独控制前后端
- 方便查看日志
- 适合开发调试

---

### 方式3：完整启动（带虚拟环境）

#### Windows
```bash
start.bat
```

#### Linux/Mac
```bash
python start.py
```

**优点**：
- 自动创建虚拟环境
- 自动安装依赖
- 适合首次使用

**缺点**：
- 首次运行较慢
- 需要网络下载依赖
