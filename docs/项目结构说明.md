# CodeForge 项目结构说明

```
llm_codegen_testgen/

├── 🌐 web/                    # 前端界面（HTML+JS）
├── 📜 scripts/                # 原始脚本和演示
├── 🛠️ tools/                  # 工具和启动脚本

```

```
│   ├── config.py            # 配置管理
│   ├── providers/           # AI提供者模块
│   │   ├── __init__.py

│   │   ├── manager.py      # 提供者管理器

│   └── evaluators/         # 代码评估器
│       ├── __init__.py
│       ├── code_quality.py # 代码质量评估
│       └── test_generator.py # 测试生成评估
├── models/                  # 数据模型
│   ├── __init__.py
│   ├── requests.py         # 请求模型
│   ├── responses.py        # 响应模型

├── services/               # 业务服务（预留）
│   └── __init__.py
├── utils/                  # 工具函数（预留）
│   └── __init__.py
└── app.py                  # FastAPI应用主入口
```

### 🔌 API层设计

- **middleware.py**: CORS、日志、错误处理等中间件
- **routes/**: 按功能模块划分的路由
  - `generation.py`: 代码生成相关API
  - `evaluation.py`: 代码质量评估API
  - `testing.py`: 测试用例生成API
  - `system.py`: 系统状态、配置管理API

### 🧠 Core层设计

- **config.py**: 统一配置管理，加载config.json和环境变量
- **providers/**: AI模型提供者抽象层
  - 支持插件化扩展新的AI模型
  - 统一的接口规范
  - 自动重试和错误处理
- **evaluators/**: 代码质量评估模块
  - BLEU分数计算
  - AST语法分析
  - 测试覆盖率评估

## 🏗️ 架构设计原则

### 1. 分层架构
- **表现层**: Web界面（templates + static）
- **API层**: FastAPI路由（api/routes）
- **业务层**: 核心逻辑（core）
- **数据层**: 模型定义（models）

### 2. 插件化设计
- **AI提供者**: 基于base.py的插件化扩展
- **评估器**: 可插拔的代码质量评估模块
- **启动脚本**: 多种启动方式满足不同需求

### 3. 配置驱动
- **外部配置**: config.json控制系统行为
- **环境分离**: 开发/生产环境独立配置
- **热更新**: 部分配置支持运行时更新

### 4. 错误友好
- **详细日志**: 完整的操作日志记录
- **用户反馈**: 清晰的错误信息和解决建议
- **优雅降级**: 部分功能失效不影响整体使用

## 🔄 扩展指南

### 添加新的AI提供者

1. 在`backend/core/providers/`创建新文件
2. 继承`BaseProvider`类
3. 实现必需的方法
4. 在`config.json`中添加配置
5. 在`manager.py`中注册

### 添加新的评估器

1. 在`backend/core/evaluators/`创建新文件
2. 实现评估接口
3. 在路由中注册新的API端点
4. 更新前端界面

### 添加新的启动方式

1. 在`tools/`目录创建新脚本
2. 遵循现有的错误处理模式
3. 添加到文档说明中
